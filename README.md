# Glaze

> Physics-backed UI laboratory for creating, customizing, and morphing high-fidelity glassmorphic animations.

Glaze is an intelligent design system that combines **real-time physics simulation** with **AI-powered code generation**. Build fluid, interactive components once—then automatically translate them into React, Vue, or Vanilla JS.

## Quick Start

```bash
# Navigate to the main app
cd glaze-ui

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000`

## Key Features

- **Physics-Driven Animations** — Control mass, viscosity, friction via an intuitive UI
- **Code-Morph Compiler** — Automatically generate clean, production-ready code in multiple frameworks
- **Glassmorphic Components** — Toasts, Modals, Loaders with premium backdrop-blur effects
- **Real-Time Customization** — Live preview as you adjust parameters
- **Multi-Language Output** — React, Vue, Vanilla JS with Tailwind CSS or raw CSS
